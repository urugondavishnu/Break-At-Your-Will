# Break-At-Your-Will

## Features

- **Customizable Break Intervals**: Set personalized intervals for work and break periods to suit individual preferences.
- **Notifications**: Receive timely reminders when it's time to take a break.
- **User-Friendly Interface**: Simple and intuitive design for easy navigation and setup.

## Getting Started

### Prerequisites

- **Java Development Kit (JDK)**: Ensure you have JDK 8 or higher installed. You can download it from the [official Oracle website](https://www.oracle.com/java/technologies/javase-jdk11-downloads.html).

### Installation

1. Clone the Repository:

   ```bash
   git clone https://github.com/urugondavishnu/Break-At-Your-Will.git
2. Navigate to the Project Directory:
   ```bash
   cd Break-At-Your-Will
3. Compile the Application:
   ```bash
   javac -d bin src/*.java
4. Run the Application:
   ```bash
   java -cp bin Main

## Usage
**Set Break Intervals**: Input your desired work and break durations.

**Start Timer**: Begin the work session; the application will notify you when it's time to take a break.

**Pause/Resume**: Flexibility to pause or resume the timer as needed.
